# 📱 ScheduleApp

**ScheduleApp** is a simple Android application that converts a college portal website into a mobile-friendly app for quick and easy access.

---

## 🚀 About the App

Many college portals are difficult to use on mobile devices.
ScheduleApp solves this by wrapping the website into a smooth, app-like experience.

🔗 Website used:
https://learner.saveetha.in/academics/people_schedule/

---

## ✨ Features

* 📅 Easy access to schedule
* ✅ Quick attendance checking
* 📝 Apply leave without hassle
* 📌 Booking system access
* 🌐 All features inside one app (no browser switching)
* 🔄 Pull-to-refresh support
* ⏳ Loading indicator while browsing
* 🔙 In-app navigation (no external browser)
* 🎬 Splash screen on launch

---

## 🛠️ Built With

* Kotlin

## 📦 Installation (APK)

1. Download the APK file
2. Open the file on your Android device
3. Enable **"Install from unknown sources"**
4. Install the app
